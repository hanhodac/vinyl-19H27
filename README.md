# VINY — THANH XUÂN (Unlimited users)

Bản này **không có phòng và không có giới hạn số người**. Mỗi người mở link sẽ có một máy đĩa riêng trên thiết bị của mình.

- Kéo tonearm xuống đĩa → đĩa quay và bài **Thanh Xuân — Da LAB** phát trên chính thiết bị đó.
- Không cần người thứ hai.
- Không cần server/WebSocket.
- Có thể có bao nhiêu người mở link cùng lúc tùy khả năng host/băng thông.

## Đưa lên GitHub Pages
1. Tạo repository mới.
2. Upload 4 file: `index.html`, `style.css`, `app.js`, `music.mp3`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. GitHub sẽ tạo cho bạn một link Pages.

Lưu ý: file MP3 có bản quyền; chỉ sử dụng khi bạn có quyền sử dụng/phân phối file đó.
